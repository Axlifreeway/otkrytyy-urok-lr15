# ОПЦ.07 «Аэропорт» — лабораторные по SQL

Лабораторные работы по базам данных, где каждая команда SQL сразу видна на схеме самолёта.
PostgreSQL работает прямо в браузере (PGlite), данные и задания у каждого студента свои — по номеру варианта.

| Папка | Что это |
|---|---|
| `lr13-3d/`, `lr14-3d/` | 3D-лабы ЛР-13 (INSERT) и ЛР-14 (UPDATE, DELETE): робот-СУБД обходит строки, 12 уровней, протокол |
| `labs/` | 2D-тетради ЛР-13, 14, 16 (брифинг, предсказания, смена, контрольный рейс); см. `labs/ПРЕПОДАВАТЕЛЮ.md` |
| `mvp/` | MVP открытого урока ЛР-15 «Посадка по запросу» |
| `teacher/` | панель преподавателя: кто где застрял, журнал команд, группы и PIN |
| `server/` | `labsrv.py` — вход по PIN, прогресс, события для панели (Python + SQLite); как выложить — `server/README.md` |
| `common/` | общий код: 3D-движок (`three/`), каркас лабы (`shell.js`), вход и синхронизация, проверка результата, стили |
| `vendor/pglite/` | PostgreSQL для браузера (PGlite 0.5.8) |
| `tests/`, `tools/` | тесты и сборка |
| `_архив/` | отклонённые и старые варианты |

## Сборка и проверка

    npm install
    npm run build    # собрать lr13-3d/game.js и lr14-3d/game.js из src/ и common/
    npm run check    # game.js в репозитории собран из текущих исходников?
    npm test         # данные вариантов не изменились, разбор команд, сервер
    npm run e2e      # все уровни 3D-лаб и тетрадей в браузере, вход по PIN → панель

`game.js` хранится в репозитории: лабу можно открыть двойным щелчком без сборки. После правки
`src/` или `common/` не забудьте `npm run build`.

`tests/variants.test.mjs` сверяет данные и задания всех вариантов 0–60 со снимком: если они
поменялись, у студентов «поедет» рассадка и сохранённый прогресс. Обновлять снимок
(`UPDATE_SNAPSHOT=1 npm test`) — только когда данные меняются намеренно.

Для сравнения картинки до и после правок: `SHOTS=папка npm run e2e` снимает сцену в начале
каждого уровня, `node tests/shotdiff.mjs папка-до папка-после` показывает долю отличающихся пикселей.
