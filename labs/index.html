Аэропорт · рабочие тетради

Одна база — весь семестр

Каждая лабораторная — смена в аэропорту. Команда SQL сразу меняет схему: пассажиры садятся и пересаживаются, чемоданы уезжают на ленту, отказ СУБД ставит штамп. Данные и задания у каждого свои — по номеру в журнале.

  1. Брифинг — свободная работа и показ на проекторе.
  2. Предскажи — сначала ответ, потом выполнение; ответ идёт в протокол.
  3. Смена — уровни: цель на схеме, нужно написать команды, которые к ней приведут.
  4. Контрольный рейс — новая задача без подсказок, две попытки сдачи.
  5. Протокол — собирается сам; студент вписывает ФИО и ответы на вопросы, печатает или сохраняет в PDF.
ЛР-13 INSERT
Открытие терминала

Пустая база, четыре зоны. Зона открывается, когда в родительской таблице появились строки. Порядок заполнения, многострочный VALUES, значения по умолчанию, три отказа.
ЛР-14 UPDATE · DELETE
Диспетчер на перроне

Пассажиры пересаживаются по проходу и уходят к выходу. Пульт не выполнит UPDATE/DELETE без SELECT с тем же условием. CASCADE, SET NULL, RESTRICT — вживую.
ЛР-15 SELECT
Посадка по запросу

MVP открытого урока. Будет переведён на общий движок тетрадей.
ЛР-16 JOIN
Зал выдачи багажа

Каждая строка ответа — линия: авиакомпания → рейс → пассажир → чемодан. Ничейные чемоданы, клубок без условия соединения, NULL при левом соединении.
