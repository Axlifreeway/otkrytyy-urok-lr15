# «Посадка по запросу» — MVP на 45 минут

Один файл `index.html`. Ни сервера, ни входа, ни панели преподавателя:
PostgreSQL работает прямо в браузере (PGlite из `../vendor/pglite`, а при
открытии двойным щелчком — с CDN), у каждого компьютера своя копия базы.

## Как открыть

* **Проще всего** — дважды щёлкнуть `index.html` (Chrome / Edge / Яндекс).
  Нужен интернет: с CDN грузятся PGlite (~3 МБ) и шрифты.
* **Для класса** — выложить файл на GitHub Pages рядом с прошлым уроком
  (`axlifreeway.github.io/...`) и дать студентам ссылку.

При первом открытии студент вводит **номер в журнале** — по нему
рассаживаются пассажиры. У соседа рассадка другая, поэтому его запрос
даёт его картинку. Пройденные рейсы запоминаются в браузере.

## Три вкладки

1. **Знакомство** — свободные запросы, схема салона, правила, примеры.
   Щелчок по креслу — строка таблицы.
2. **Предскажи салон** — запрос уже написан; студент щёлкает кресла,
   которые, по его мнению, загорятся, и проверяет. Три запроса: ловушка
   скобок, ловушка `= NULL`, порядок + `LIMIT`.
3. **Рейсы** — 9 уровней «обратной задачи»: голубым показана цель,
   нужно написать запрос, который даст ровно её. Не совпало — лишние
   кресла красные, недостающие пунктиром. После трёх промахов —
   подсказка. Все 9 — самолёт улетает.

Запросы выполняются в транзакции с откатом: `DELETE` и `DROP` базу не
испортят.

## 45 минут

| Мин. | Что | Вкладка |
|---|---|---|
| 0–3 | «Как авиакомпания говорит компьютеру, кого сажать первым?» | Знакомство, на проекторе |
| 3–10 | Показ: бизнес-класс; запрос без `seat`; посадка с хвоста | Знакомство |
| 10–17 | Все вместе: три запроса на предсказание, обсуждение | Предскажи салон |
| 17–40 | Каждый сам: рейсы 1–9 | Рейсы |
| 40–45 | Кто сколько рейсов выполнил; ДЗ — ЛР-15 на своей базе | — |

## Ограничения MVP

* Эталонные запросы уровней лежат в коде страницы — студент, открывший
  исходник, их найдёт. Для открытого урока это не важно; для зачётной
  работы — нужен сервер (практикум).
* Прогресс хранится только в браузере этого компьютера; преподаватель
  его не видит.
* Без интернета не запустится (PGlite и шрифты с CDN).
