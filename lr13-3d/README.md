# ЛР-13 · INSERT · «Открытие рейса» (3D)

Открыть `index.html` в Chrome (двойным щелчком или с сервера). PostgreSQL (PGlite) берётся из `../vendor/pglite/`; если страница открыта двойным щелчком — с CDN, тогда нужен интернет (и для шрифтов тоже).

Самолёт в начале пуст. Всё, что появляется на борту, — строки, вставленные студентом:
рейс — на табло, кресло — падает на рейки, пассажир — идёт с трапа к своему месту, чемодан — летит с тележки на полку над рядом владельца.
Робот-СУБД несёт каждую строку из VALUES по очереди и показывает карточку: что указано, что подставлено по умолчанию (синим), какой столбец нарушил правило (красным).
При отказе — ROLLBACK: уже вошедшие пассажиры возвращаются в очередь, чемоданы — на тележку.

| № | Уровень | Что отрабатывается |
|---|---|---|
| 1 | Рейс на табло | INSERT одной строки, перечень столбцов, текст и время в кавычках |
| 2 | Ещё два рейса | несколько строк одной командой, NULL |
| 3 | Бизнес-класс | 8 кресел одной командой (справочник seat) |
| 4 | Эконом по умолчанию | DEFAULT: столбец cls не указывать |
| 5 | Первый пассажир | DEFAULT для meal; прогноз |
| 6 | Семья | разные значения в строках, слово DEFAULT в VALUES |
| 7 | Багаж | внешний ключ: id владельца ищется щелчком по пассажиру |
| 8 | Сначала кресло | порядок вставки (FK); прогноз |
| 9 | Ошибка в списке | атомарность: ошибка в одной строке отменяет все; прогноз |
| 10 | Сверка | SELECT count(*) по четырём таблицам |
| 11 | Три отказа | FOREIGN KEY, NOT NULL, CHECK |
| 12 | Последние на борт | контрольный: seat → passenger → baggage, взлёт |

Номер в журнале задаёт рейс, места, ФИО, бирки и вес — у соседей данные другие.
Проверяется итоговое состояние базы (плюс «одной командой» и «без столбца» там, где это цель уровня).
После финала — протокол (печать в PDF): команды, ответы СУБД, промахи, прогнозы, 4 вопроса, оценка (9 баллов авто + 1 за ответы).
Прогресс хранится в браузере отдельно для каждого номера; общий номер с ЛР-14.

Исходники: `src/` — data.js (данные и уровни), parse.js (разбор команды, пояснения к ошибкам), scene.js (салон, трап, тележка), main.js (робот несёт строки, проверка уровней).
Общее с ЛР-14 — в `../common/` (3D-движок, вход, протокол, стили). Сборка из корня репозитория: `npm install`, затем `npm run build`.
