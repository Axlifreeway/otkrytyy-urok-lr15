# ЛР-14 «UPDATE и DELETE» — 3D, 12 уровней

Открыть `index.html` (Chrome / Edge / Яндекс). Ввести номер в журнале — по нему рассадка, багаж и задания.
Уровни открываются по очереди. Прогресс хранится в браузере этого компьютера.

| № | Уровень | Пункт ЛР |
|---|---|---|
| 1 | Детское питание — UPDATE по условию | ч. 1, несколько строк |
| 2 | Остальным — стандарт — IS NULL против = NULL | ч. 1, пустой столбец |
| 3 | К окну — по первичному ключу (робот идёт сразу к строке) | ч. 1, одна строка |
| 4 | Весы врали — weight_kg = weight_kg + 2 | ч. 1, от текущего значения |
| 5 | Не пролезло — CHECK посреди обхода и ROLLBACK | команда целиком или никак |
| 6 | Неявка — DELETE одной строки | ч. 2, п. 5 |
| 7 | Снят с рейса — ON DELETE CASCADE | ч. 2, п. 6 |
| 8 | Программа закрыта — ON DELETE SET NULL | ч. 2, п. 6 |
| 9 | Неудаляемый рейс — RESTRICT | ч. 2, п. 6 |
| 10 | Возврат билетов — active = false вместо удаления | ч. 2, п. 7 |
| 11 | Три отказа — UNIQUE, CHECK, FOREIGN KEY | ч. 3 |
| ✈ | Последний рейс — контрольный, без подсказок | — |

Перед уровнями 5, 7, 8, 9 — прогноз «что будет». После последнего рейса — итоги и протокол (печать / PDF).
SELECT перед UPDATE/DELETE с тем же WHERE — «прицел»: числа сверяются, команды без прицела попадают в протокол.

## Файлы
* `game.js` — собранная игра (Three.js + модель робота + логика), работает без сборки.
* `src/` — исходники. Пересборка: `npm i three@0.170.0 esbuild` и
  `npx esbuild src/main.js --bundle --format=iife --minify --outfile=game.js`.
