# ЛР-14 «UPDATE и DELETE» — 3D, 20 уровней

Открыть `index.html` (Chrome / Edge / Яндекс). Ввести номер в журнале — по нему рассадка, багаж и задания.
Уровни открываются по очереди. Прогресс хранится в браузере этого компьютера.

| № | Уровень | Пункт ЛР |
|---|---|---|
| 1 | Детское питание — UPDATE по условию | ч. 1, несколько строк |
| 2 | Остальным — стандарт — IS NULL против = NULL | ч. 1, пустой столбец |
| 3 | Год рождения уточнён — NULL заменяется значением | ч. 1, одна строка |
| 4 | К окну — по первичному ключу (робот идёт сразу к строке) | ч. 1, одна строка |
| 5 | Фамилия изменилась — текстовое значение | ч. 1, одна строка |
| 6 | Два столбца сразу — SET a = …, b = … | ч. 1, несколько столбцов |
| 7 | Ручная кладь — DELETE по двум условиям | ч. 2, п. 5 |
| 8 | Весы врали — weight_kg = weight_kg + 2 | ч. 1, от текущего значения |
| 9 | Не пролезло — CHECK посреди обхода и ROLLBACK | команда целиком или никак |
| 10 | Неявка — DELETE одной строки | ч. 2, п. 5 |
| 11 | Снят с рейса — ON DELETE CASCADE | ч. 2, п. 6 |
| 12 | Программа закрыта — ON DELETE SET NULL | ч. 2, п. 6 |
| 13 | Неудаляемый рейс — RESTRICT | ч. 2, п. 6 |
| 14 | Рейс перенаправлен — UPDATE вместо удаления | ч. 1 |
| 15 | Скидка выросла — discount = discount + 5 | ч. 1, от текущего значения |
| 16 | Повышение до золота — ссылка на другую программу | ч. 1, внешний ключ |
| 17 | Возврат билетов — active = false вместо удаления | ч. 2, п. 7 |
| 18 | Передумал — active = true обратно | ч. 2, п. 7 |
| 19 | Охота на ограничения — UNIQUE, CHECK, FOREIGN KEY | ч. 3 |
| ✈ | Последний рейс — контрольный, без подсказок | — |

Перед уровнями «Не пролезло», «Снят с рейса», «Программа закрыта», «Неудаляемый рейс» — прогноз «что будет». После последнего рейса — итоги и протокол (печать / PDF).
Уровни 3, 5, 6, 7, 14, 15, 16, 18 добавлены, чтобы лаба занимала пару (90 минут); прошедшим лабу раньше они засчитаны автоматически.
SELECT перед UPDATE/DELETE с тем же WHERE — «прицел»: числа сверяются, команды без прицела попадают в протокол.

## Файлы
* `game.js` — собранная игра (Three.js + модель робота + логика), работает без сборки.
* `src/` — исходники: data.js (данные и уровни), parse.js (разбор команды, пояснения к ошибкам), scene.js (салон, полки, стойка программ), main.js (обход строк роботом, проверка уровней).
  Общее с ЛР-13 — в `../common/` (3D-движок, вход, протокол, стили).
  Пересборка из корня репозитория: `npm install`, затем `npm run build`.
